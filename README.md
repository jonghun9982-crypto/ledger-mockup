# 생각통장 시안

아이폰에서 위 링크를 열면 하나의 미니 앱으로 볼 수 있어요. 아래 탭으로 화면을 바꿔요.

- 생각통장 — `#card` (카드의 빈칸에서 「카드결제 내역 붙이기」로 결제 문자를 붙여 넣으면 맨 앞에 새 카드가 생겨요. 「+ 새 이름」으로 직접 쓴 이름을 스티커로 붙일 수 있어요)
- 생각 연습 — `#bubble` (아래 예시 바꾸기: 처음 보는 가게 / 아는 가게 / 여러 번 결제)
- 내 사전 — `#dict`

예전 링크 `bubble.html`은 생각 연습 탭으로 자동 이동해요. 화면 속 숫자와 거래는 모두 목업용 예시예요.
