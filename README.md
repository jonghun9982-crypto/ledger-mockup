# 통장 번역기 시안

아이폰에서 위 링크를 열면 하나의 미니 앱으로 볼 수 있어요. 아래 탭으로 화면을 바꿔요.

- 카드 게임 — `#card` (「+ 새 이름」으로 직접 쓴 이름을 스티커로 붙일 수 있어요)
- 말풍선 — `#bubble` (아래 예시 바꾸기: 처음 보는 가게 / 아는 가게 / 여러 번 결제)
- 내 사전 — `#dict`

## 통장 PDF로 카드 만들기 (v1)

- 카드 게임 탭의 「통장 PDF 넣기」 카드에서 「📄 파일에서 고르기」로 거래내역서 PDF를 골라요. v1은 **우리은행**(WON 앱·VestMail 메일 PDF)을 읽고, 다른 은행은 추측해서 읽어요.
- PDF는 **폰 안에서만** 읽어요. 서버로 보내지 않아요. 읽는 도구(pdf.js)와 한글 글꼴 표는 `pdfjs/`에 들어 있어요.
- 읽은 거래, 내 사전, 스티커는 이 폰 브라우저(IndexedDB)에만 저장돼요. 비밀번호, PDF 원본, 예금주 이름은 저장하지 않아요. 「이 폰에서 다 지우기」로 모두 지울 수 있어요.
- 시험용 가짜 PDF: `samples/woori-example-oct.pdf`, `samples/woori-example-sep-locked.pdf`(비밀번호 900101). 이름·가게·금액은 모두 지어낸 것이에요.
- 「예시 통장으로 해 보기」를 누르면 예전 예시 카드 8장으로 해 볼 수 있어요.

예전 링크 `bubble.html`은 말풍선 탭으로 자동 이동해요. 화면 속 숫자와 거래는 모두 목업용 예시예요.
